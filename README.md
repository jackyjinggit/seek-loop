# 寻·环 seek·loop

> PANDA JAM · 48H 科幻游戏创作团队赛 · 官方主题《环 Cycle》

一个男人替另一个男人送一支口红。到门口才知道，自己是第 47 个。

《寻·环》是一部科幻视觉小说：Y 要远航，托 X 把珊瑚红口红送给 Z——「若她挽留，我就留下」。Z 用克隆意识驻留技术留在小屋等他；回传协议是初代 X 写的，它不邪恶，只是把「未送达」当成待修复的 bug，一遍遍重跑。

**环不是重复，是闭合，每次让规则偏一度。**

## 特性

- 单线叙事 + 一个硬分叉（茶桌上那杯茶），三个结局：送达 / 门外 / 真结局「不再等待」
- 四次环视：口红 / 茶包 / 书 / 信标，点一次浮现一个，错过不补
- 集齐四道具进入隐藏结局「门外」；真结局解锁尾声·口红架解谜——编号漂移了，颜色不骗人
- 「记忆残留」收集页：8 张立绘 + 13 张设定稿，按结局与收集度解锁
- 场景音效 18 处，室外 / 室内 BGM 双线

## 运行

1. 安装 [Ren'Py 8.5+ SDK](https://www.renpy.org/latest.html)
2. 在 Ren'Py Launcher 中选择本目录（含 `game/`）作为工程打开
3. 点「启动项目」

操作：鼠标点击推进；Ctrl / Tab 快进；底部快捷栏含历史、自动、存读档。

## 目录

```
game/
├── script.rpy      # 工程入口
├── story.rpy       # 主线：五场景单线 + 三结局
├── ch5.rpy         # 尾声 · 第五章「不再等待」（口红架解谜）
├── panorama.rpy    # 环视与道具卡
├── gallery.rpy     # 记忆残留收集页
├── portraits.rpy   # 立绘轮换
├── monitor.rpy     # 街头监视点彩蛋
├── staff.rpy       # 片尾职员表
├── zh_screens.rpy  # 中文界面层
└── images/ audio/  # 美术与音频资产
```

引擎层文件（`gui.rpy` / `options.rpy` / `screens.rpy`）随仓库提供，字体在 `game/` 根。
